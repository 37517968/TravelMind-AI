# 旅行行程规划 Skill

## 概述

此 Skill 负责生成完整的旅行行程规划，包括每日景点安排、餐饮推荐、住宿建议、路线规划等。

## 前置条件

- 用户必须提供目的地（如果未提供，需要询问用户）
- 天数可选（默认3天）
- 预算可选（默认中等预算）

## 参数定义

### 必需参数
- `destination` (string): 目的地城市名称
  - 示例："上海"、"北京"、"杭州"

### 可选参数
- `days` (integer): 旅行天数
  - 默认值：3
  - 范围：1-30
  
- `budget` (integer): 预算（人民币元）
  - 默认值：3000
  - 说明：总预算，非人均
  
- `travelers` (integer): 出行人数
  - 默认值：2
  
- `travel_type` (string): 旅行类型
  - 可选值："休闲"、"紧凑"、"深度游"
  - 默认值："休闲"
  
- `start_date` (string): 出发日期
  - 格式：YYYY-MM-DD
  - 默认值：一周后
  
- `interests` (array): 兴趣偏好
  - 可选值：["美食", "文化", "自然", "购物", "亲子"]
  - 默认值：[]

## 工作流程

### 步骤 1：参数验证
- 检查必需参数是否存在
- 验证参数的有效性
- 如果缺少必需参数，返回错误提示

### 步骤 2：查询天气信息
```
调用 weather-tool
输入：destination
输出：未来几天的天气预报
```

### 步骤 3：搜索 POI 信息
```
调用 poi-search-tool 三次：
1. 搜索景点：keyword="景点"
2. 搜索餐厅：keyword="美食"
3. 搜索酒店：keyword="酒店"
```

### 步骤 4：检索知识库
```
使用 RAG Advisor 检索相关旅行方案
查询条件：destination + travel_type
返回：top 5 相关方案
```

### 步骤 5：生成行程
```
综合以上信息，使用大模型生成详细行程：
- 每日景点安排（考虑天气）
- 餐饮推荐（结合当地特色）
- 住宿建议（考虑位置和预算）
- 时间安排（避免过度奔波）
```

### 步骤 6：规划路线
```
为每日行程调用 route-planning-tool
计算景点之间的最优路线
```

### 步骤 7：下载景点图片（可选）
```
调用 resource-download-tool
为主要景点下载图片
```

## 输出格式

返回 Markdown 格式的行程规划：

```markdown
【{destination} {days}天智能行程规划】

🌤️ 天气情况：
{weather_info}
```

## 最佳实践

### 1. 天气适配
- 雨天：优先安排室内景点（博物馆、商场）
- 晴天：优先安排户外景点（公园、古镇）
- 高温：避免中午户外活动

### 2. 路线优化
- 同一区域的景点安排在同一天
- 避免来回奔波
- 考虑交通拥堵时段

### 3. 时间分配
- 每个景点预留足够时间
- 留出用餐和休息时间
- 预留弹性时间应对突发情况

### 4. 知识库利用
- 优先参考高点赞的方案
- 学习优质方案的行程安排
- 借鉴实用的旅行建议

## 示例

### 示例 1：基础行程规划

**用户输入**：
```
帮我规划上海三日游
```

**参数提取**：
```json
{
  "destination": "上海",
  "days": 3,
  "budget": 3000,
  "travelers": 2,
  "travel_type": "休闲"
}
```

**执行流程**：
1. 查询上海天气 → 晴，20-25℃
2. 搜索景点 → 外滩、东方明珠、豫园...
3. 搜索餐厅 → 南翔小笼、老正兴...
4. 搜索酒店 → 如家、汉庭...
5. 检索知识库 → 找到3个相关方案
6. 生成行程 → 第一天：外滩→南京路→豫园...
7. 规划路线 → 地铁2号线...

## 故障排查

### 问题 1：无法识别目的地

**症状**：参数提取失败，destination 为 null

**解决方案**：
1. 提示用户明确指定目的地
2. 返回错误信息："请指定目的地，例如：上海、北京、杭州等"

### 问题 2：天气查询失败

**症状**：weather-tool 返回错误

**解决方案**：
1. 使用历史平均天气数据
2. 在行程中标注"天气信息仅供参考"

### 问题 3：POI 搜索失败

**症状**：poi-search-tool 返回空结果

**解决方案**：
1. 使用知识库中的景点信息
2. 使用内置的热门景点列表

### 问题 4：知识库检索无结果

**症状**：RAG Advisor 未找到相关方案

**解决方案**：
1. 降低相似度阈值
2. 使用通用的旅行规划模板

## 注意事项

1. **参数验证**：始终验证用户输入的参数是否合理
2. **错误处理**：优雅地处理工具调用失败的情况
3. **用户体验**：生成的行程应该易读、实用
4. **性能优化**：并行调用多个工具以提升速度
5. **知识库优先**：优先使用知识库中的优质方案
