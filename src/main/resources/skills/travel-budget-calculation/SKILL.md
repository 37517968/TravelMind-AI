# 旅行预算计算技能

## 使用时机
当用户的问题涉及旅行费用、预算计算、价格查询时，调用此技能。

## 前置条件
**必须先执行 travel-itinerary-planning 技能**，确保上下文中包含：
- destination（目的地）
- days（天数）
- itinerary（行程内容）

## 执行步骤

### 1. 验证前置条件
检查上下文中是否有行程信息，如果没有，返回错误：
```
请先规划行程，再计算预算。您可以说：帮我规划{destination}旅游
```

### 2. 计算交通费用
- **市内交通**：根据行程中的景点，使用 `route-planning-tool` 计算距离，估算费用
  - 公交/地铁：约 50-80 元/天
  - 出租车/网约车：约 100-150 元/天
- **往返交通**：根据目的地估算
  - 一线城市：1000-1500 元/人
  - 热门旅游城市：1500-2500 元/人
  - 其他城市：800-1200 元/人

### 3. 计算住宿费用
使用 `web-search-tool` 搜索"{destination} 酒店 价格"，根据结果估算：
- 一线城市：300-500 元/晚
- 新一线城市：250-400 元/晚
- 其他城市：200-300 元/晚

计算公式：住宿费用 = 价格/晚 × 天数 × 房间数

### 4. 计算景点门票费用
从行程中提取景点列表，使用 `web-search-tool` 查询每个景点的门票价格。
如果查询失败，使用默认值：80 元/人/景点

### 5. 计算餐饮费用
根据城市等级估算：
- 一线城市：150-250 元/人/天
- 新一线城市：120-200 元/人/天
- 其他城市：100-150 元/人/天

### 6. 计算其他费用
其他费用 = (交通 + 住宿 + 门票 + 餐饮) × 10%
包括：购物、小费、应急等

### 7. 生成省钱建议
提供个性化的省钱建议：
- 提前预订优惠
- 错峰出行
- 联票优惠
- 当地特色小吃
- 公共交通

### 8. 输出格式
按以下格式输出：

```
【{destination} {days}天旅行预算详细计算】
出行人数：{travelers}人

🚗 交通费用：{transport_cost} 元
  - 市内交通：{local_transport} 元
  - 往返交通：{round_trip} 元

🏨 住宿费用：{accommodation_cost} 元
  - 约 {price_per_night} 元/晚 × {days} 晚

🎫 景点门票：{attraction_cost} 元
  - {attraction1}：{price1} 元
  - {attraction2}：{price2} 元

🍜 餐饮费用：{meal_cost} 元
  - 约 {price_per_day} 元/人/天 × {days} 天 × {travelers} 人

💰 其他费用：{other_cost} 元
  - 购物、小费、应急等（约10%）

━━━━━━━━━━━━━━━━━━━━
💵 预计总费用：{total_cost} 元
👥 人均费用：{per_person_cost} 元
📊 日均费用：{per_day_cost} 元/人/天

💡 省钱建议：
{saving_tips}
```

## 注意事项
1. 始终检查是否有行程信息
2. 标注价格来源（实时查询/历史数据/估算）
3. 提示用户实际费用可能有 ±20% 的误差
4. 考虑季节因素（旺季/淡季）
